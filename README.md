# AkhiSave

AkhiSave is a mobile-first public social media tools platform. The current live focus is Instagram downloading and public profile tools, powered by SocialKit through a Cloudflare Worker.

## Current tools
- Instagram Photo Downloader
- Instagram Reels Downloader
- Instagram Video Downloader
- Instagram Profile Viewer
- Instagram DP Downloader
- Instagram Profile Posts
- Instagram Profile Reels

Story downloading remains disabled until reliable API support is verified.
